# 🐘 Estudos de PHP

Este repositório reúne exercícios, scripts e projetos desenvolvidos durante meus estudos de PHP, com foco em lógica de programação, manipulação de dados e desenvolvimento web back-end.

## 🚀 O que está sendo estudado

### 📘 Fundamentos

* Sintaxe básica do PHP
* Variáveis e tipos de dados
* Operadores aritméticos e lógicos
* Estruturas condicionais (`if`, `else`, `switch`)
* Estruturas de repetição (`for`, `while`, `foreach`)

### 🛠️ Manipulação e Lógica

* Criação de funções
* Manipulação de arrays
* Uso de superglobais (`$_GET`, `$_POST`, `$_SESSION`, `$_COOKIE`, `$_SERVER`)
* Organização e modularização de código

### 🌐 Web e Integração

* Formulários e validação de dados
* Integração entre front-end e back-end
* Includes e requires
* Sessões e autenticação
* Conexão com banco de dados utilizando PDO

### Exercícios Práticos

* Formulários dinâmicos
* Exercícios de lógica
* Manipulação de dados
* Estruturas de controle

## 🛠️ Como executar os projetos

### Via terminal

```bash id="5d78xy"
php nome-do-arquivo.php
```


